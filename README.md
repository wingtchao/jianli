# 短剧剪辑师个人简历（GitHub Pages 版）

可直接发布到 GitHub Pages 的静态简历网站。**纯静态、零依赖、零构建**，推上去就能访问。

---

## 一、目录结构

```
.
├── index.html              ← 页面本体（版式 + 交互，一般不用改）
├── assets/
│   └── resume-data.js      ← 全部文字内容，改这个就够了
├── .nojekyll               ← 让 GitHub Pages 跳过 Jekyll 处理
└── README.md               ← 本说明
```

只有 `assets/resume-data.js` 需要动。版式、动画、打印样式都在 `index.html` 里，改内容不会碰到它。

---

## 二、发布到 GitHub Pages

### 方式 A：网页操作（最简单，不用装任何工具）

1. 登录 GitHub → 右上角 `+` → **New repository**
2. 仓库名建议用 `你的用户名.github.io`，这样访问地址最干净；随便起名也可以
3. 勾选 **Add a README file** → **Create repository**
4. 进仓库 → **Add file** → **Upload files**
5. 把本文件夹里的 `index.html`、`.nojekyll` 拖进去 → **Commit changes**
6. 再 **Add file** → **Create new file**，文件名填 `assets/resume-data.js`，把本地同名文件的内容整段粘贴进去 → **Commit changes**
   （GitHub 网页端不能直接建文件夹，靠"文件名里带 `/`"就会自动创建目录）
7. 仓库 **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 `main` / `/ (root)` → **Save**
8. 等 1-2 分钟，页面顶部会出现访问地址：`https://你的用户名.github.io/仓库名/`

### 方式 B：命令行

```bash
cd 本文件夹
git init
git add .
git commit -m "简历站点首版"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

推送后同样到 **Settings → Pages** 开启，Branch 选 `main` / `/ (root)`。

## 三、修改个人信息（两种方式，任选）

### 方式 1：直接在 GitHub 网页改（推荐，最快）

1. 仓库里点开 `assets/resume-data.js`
2. 右上角铅笔图标 **Edit this file**
3. 改文字 → **Commit changes**
4. 1-2 分钟后线上自动更新

文件里每个栏目都有中文注释标记，按注释找位置即可，例如：

| 注释标记 | 对应页面栏目 |
|---|---|
| `profile` | 姓名、头衔、求职意向、联系方式、能力标签 |
| `stats` | 顶部 4 个大数字 |
| `works` | 爆款作品图文卡 |
| `methods` | 剪辑方法论 |
| `skills` | 软件熟练度 |
| `experiences` | 工作经历时间线 |
| `insights` | 行业认知 |
| `education` / `certificates` | 教育背景、证书 |
| `quotes` | 合作方评价 |

改的时候注意两点：
- 文字用**英文双引号**包起来，别用中文引号
- 每项之间用英文逗号隔开，最后一项后面不加逗号

### 方式 2：在页面上填表（不用碰代码）

1. 打开简历页面 → 点右下角 **「编辑内容」**
2. 侧边面板按栏目列出所有字段，直接填写，页面**实时预览**
3. 改完点 **「导出 resume-data.js」** 下载文件
4. 用下载的文件覆盖仓库里的 `assets/resume-data.js`，提交推送

> 面板里的修改会先存成**本机浏览器草稿**（页面顶部有青色提示条），换设备或分享链接都带不走。只有导出并覆盖文件，改动才会同步到线上。
> 点「恢复文件原样」可丢弃草稿。

## 四、当前内容状态（重要）

**个人信息已是你的真实资料**，但以下栏目仍是模板示例，发布前请替换：

- **爆款作品 6 部**：剧名、公司、播放数据全部为虚构示例，每张卡片底部有橙色提示条标注
- **工作经历 / 教育背景 / 证书 / 合作方评价**：同为虚构示例
- **数据看板 4 个数字**：示例值，请改成你的真实成绩
- **作品封面图**：目前是网络示意图链接，**建议换成你自己的剧集截图或海报**

### 换封面图的做法

把图片传到任意图床或 GitHub 仓库，拿到图片链接，填到作品项的 `image` 字段：

```js
image: "https://你的图片链接.jpg",
```

想直接放在仓库里也行：在本目录建 `images/` 文件夹放图，然后写相对路径 `image: "images/xxx.jpg"`。

> `alt` 字段填一句图片描述，用于无障碍朗读和图片加载失败时的显示。

## 六、常见问题

**页面打开是空白 / 排版错乱**
多半是 `assets/resume-data.js` 语法出错（漏引号、漏逗号、用了中文标点）。浏览器按 F12 → Console 看红色报错，会指出行号。

**图片不显示**
封面位置会自动降级为"渐变底 + 剧名文字"，不影响阅读。检查 `image` 链接是否可公开访问；部分图床有防盗链，建议改用 GitHub 仓库内的相对路径。

**线上更新没生效**
GitHub Pages 有缓存，等 1-2 分钟，或强制刷新（Windows 按 `Ctrl + F5`）。

**想要独立域名**
仓库 Settings → Pages → Custom domain 填入域名，并按 GitHub 文档配置 DNS。

## 七、隐私提醒

这份简历包含手机号、邮箱、微信号等个人信息。发布到 GitHub 公开仓库后，**任何人都能看到并被搜索引擎收录**。

建议二选一：
- 仓库设为 **Private**，用 GitHub Pages 的私有访问（需 Pro/Team 套餐），或仅本地打开使用
- 保持公开，但在数据文件里只留邮箱，去掉手机号和微信号
